# 1.0.0 正式 Chrome 核验记录

2026-10-05，版本 `1.0.0`、构建 `20261005.2` 在 Windows 用户 Chrome 154.0.8037.93 中进行核心流程测试。用户按正式侧栏步骤提供 JSON 报告及实际保存目录，验证者独立读取报告和磁盘文件，没有转码或显示测试图片。

## 核验方法与结果

用 Node.js 读取正式报告及原型阶段的 17 张正文图片基线，按 SHA-256 关联，同时比较 ready 状态、MIME、字节数、宽高，并核对保存请求与结果的编号、哈希和字节数。

- 扫描 48 个来源，45 张可保存，3 张字节重复，0 张无法提取，warnings 为空。
- 17/17 张正文图片全部匹配基线，对应正式清单编号 5–21；其他网页图片也进入通用清单。
- 捕获与保存来源相同，请求 3 张，3 张结果均为 saved，批次 complete。
- JSON 报告已实际下载；页面标题子目录正确创建，标题中的 `/` 被清洗成 `_`。

再使用 .NET 文件读取、SHA-256 与 System.Drawing 解码元数据，独立核对实际目录中的三个文件：

核心取图、多选、目录保存、标题子目录和报告导出通过。没有直接观察工具栏打开时的窗口变化，也没有以一次写入成功推断重启后的授权恢复。其余平台行为的状态见[验证状态](../verification.md)。

# 原型路线验证记录

状态：已完成，后续正式版的行为以[使用说明](../usage.md)和[当前架构](../design/image-save.md)为准。此文保留早期选择路线的理由，不是当前安装指南。

## 需求与路线

目标是保存当前页已加载图片，支持一键全部、多选、任意目录和按页面标题创建子目录。图片在本机处理，保留格式与原字节，不依赖账户、云服务或本地辅助程序，不主动滚动或抓取未加载内容。

某些现成下载器未能提取测试页面上可见的正文图，因此先验证两个关键能力，再写正式界面：

1. Chrome `pageCapture` 快照能否包含已加载图片的原始字节，并与页面图片清单对应。
2. 扩展文档能否通过 File System Access 选择任意目录，批量写入并读取文件校验。

取图由受控 MHTML 快照解析完成；目录由用户手势授权的目录句柄完成。没有采用反复请求图片服务器、逐图另存为、Cookie 导出或浏览器调试权限路线。

## 原型证据

原型 `0.0.1` 在验证页中执行：17/17 张正文图成功提取，缺失 0；选择的 3 张写入磁盘，独立检查字节数、尺寸与 SHA-256 全部一致，首张另与独立原图字节一致。

这个阶段证明快照与目录路线可行，不能证明后来的原生侧栏集成行为。正式 `1.0.0` 改用当前窗口侧栏，随后完成[正式核心核验](extension-native-validation.md)。

真实页面地址、私人图片、原型下载报告、本机路径和完整过程记录只保存在原始工作区的 Git 忽略目录。

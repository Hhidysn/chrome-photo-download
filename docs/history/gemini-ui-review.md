# Gemini 界面独立评审

2026-10-05，使用 Gemini 3.8 Flash 进行只读文本界面评审，未提供真实图片、浏览器凭据或完整聊天记录，也未授权修改项目文件。

任务成功返回文字结果；请求与运行时报告模型一致。评审用于比较界面方案，不作为插件功能正确的证据。完整调用记录留在本地 Git 忽略目录。

采纳建议：原生 Side Panel 保持网页可操作；固定来源提示；独立的全部 / 所选下载语义；直接点击触发目录授权；保存时冻结批次；失败增量重试；Blob 缩略图、延迟加载和释放；Shift 连选与键盘操作。

评审建议每 tab 一个侧栏；实际选择每窗口一个侧栏加明确的冻结来源，这样切换标签时更容易保持当前保存批次。每窗口来源键、唯一请求和忙时队列防止串页。

没有采纳跨重启自动保存字节断点、点击图片自动滚动原网页和通用虚拟列表框架。本版使用任务元数据记录中断，用户重新读取后补下载，不增加高容量存储权限或额外控制原网页的行为。

Gemini 对侧栏目录 API 支持的判断作为候选意见；实际结论以官方来源、原有取图实验与正式 Chrome 集成验证为准。未把模型“更熟悉 Chrome”作为可靠性保证。

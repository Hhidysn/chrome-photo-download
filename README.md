# 页面图片保存

Windows 桌面 Chrome 的本地图片保存扩展。在当前窗口的侧边栏查看网页已加载图片，一键保存全部或自由多选，支持选择目录、按页面标题创建子目录、原图去重、同名避让和失败重试。无需账号，图片与报告在本机处理。

## 快速开始

1. 在仓库页面选择 **Code → Download ZIP**，下载并解压，或用 Git 克隆本仓库。
2. 在 Chrome 打开 `chrome://extensions/`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择解压后项目里的 **extension** 目录（包含 `manifest.json`）。
3. 固定“页面图片保存”的绿色图标，在目标网页点击它，选择保存目录，再下载所选或范围内全部图片。

首次或授权失效时，需要点击侧边栏按钮选择目录 / 授权。保存期间保持面板打开。默认快捷键为 `Alt+Shift+D`；快捷下载也需要有效的目录授权。

当前版本为 **1.0.0**。清单最低 Chrome 版本为 116，实际验证环境与兼容边界见下方文档。使用最短边筛选可排除页面中的小图与图标。

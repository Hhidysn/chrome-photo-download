## 已知限制

- 仅处理扫描时已加载且仍保留在可访问 DOM 中的图片；不自动滚动、翻页或抓取未加载内容。
- 不保证取得跨域框架、关闭 Shadow DOM、canvas 内绘制、已卸载虚拟列表或缺少加载时间记录的背景图。
- 可见范围是几何和 CSS 判断，不是逐像素遮挡检测。
- 扫描上限为 30000 个元素 / 5000 张图片，快照上限为 150 MiB；达到上限会提示或拒绝继续。
- 面板关闭可能中断批次；只保存任务元数据，不跨重启自动恢复写入。
- 同名避让不能提供对外部程序并发创建文件的独占保证；写入失败可能留下空文件或部分文件，不自动删除。

更详细的操作语义和格式范围见[使用说明](usage.md)。

页面图片保存 1.0.0 — Windows 桌面 Chrome 116+

安装：
1. 将此 ZIP 解压到一个固定目录。不要移动或删除该目录。
2. 在 Chrome 手动打开 chrome://extensions/，打开“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的目录。
4. 将“页面图片保存”的蓝色下载图标固定到工具栏；此前的技术验证扩展可关闭。

使用：
在已加载图片的网页点击扩展图标，侧边栏会读取图片，网页保持打开。
选好目录后，可直接下载范围内全部图片，或勾选缩略图再下载所选。
默认在所选根目录内按页面标题创建子目录，可修改名称或关闭此选项。
当前屏幕可见范围：滚动网页后点击“滚动后更新可见范围”。
Shift + 单击可连续多选；在图片列表中 Ctrl+A 全选，空格切换勾选。
Alt+Shift+D 快捷保存当前范围全部。第一次或授权失效时需要在侧栏点击下载授权。
快捷键冲突可在 Chrome 的扩展程序快捷键设置中修改。

同名文件会增加 (1)、(2) 等后缀，不覆盖已有文件。
保存中保持侧边栏打开；“停止后续保存”会先完成当前文件。
未成功的保存可点“重试未成功项”，图片无法提取时点“刷新图片”。
关闭面板或浏览器可能中断批次；重新打开会提示已记录的成功数量。
不会在重启后自动继续写入。可导出报告核对，再选择未完成图片补存。
“导出报告”由 Chrome 常规下载保存 JSON，不包含图片字节。

常见范围：普通 img、开放 Shadow DOM、同源框架，以及资源时间记录中已加载的 CSS 背景图。
跨域框架、关闭的 Shadow DOM、canvas 内绘制和已卸载的虚拟列表不保证取得。
不主动加载后续图片；扫描最多 30000 个元素 / 5000 张图片，快照最多 150 MiB，超过时明确提示。
所有选图和图片保存都在本机处理，不上传图片、页面或报告。

# 使用说明

当前代码版本为 1.0.0，构建标识 `20261005.3`。适用于 Windows 桌面 Chrome，清单最低版本为 116；实际验证环境与未测行为见[验证状态](verification.md)。

## 保持在当前窗口

将扩展固定到 Chrome 工具栏，在要保存的普通 HTTP/HTTPS 网页点击扩展图标。扩展打开原生侧边栏并读取图片，不创建新的标签页或窗口。

来源在点击图标时固定。切换标签、刷新网页或关闭来源标签后，已经读取的图片仍属于原来的任务。面板会提示来源发生变化；在另一个网页点击图标，才会开始读取那个网页。

保存中再次点击另一个页面的扩展图标，会在当前任务结束后读取最后请求的新来源，不改变正在保存的图片和目录。

## 选图和范围

- “全部已加载”覆盖扫描时仍保留在页面中的已加载图片，不自动滚动、翻页或加载后续内容。
- “当前屏幕可见”按网页视口、显示属性、透明度和滚动容器裁剪计算。滚动网页后点击“滚动后更新可见范围”；它更新范围，不重新请求图片。
- 尺寸筛选对普通图片使用页面自然尺寸；CSS 背景使用元素尺寸。
- “全选”“反选”“清空”只操作当前范围。切换范围后，隐藏在其他范围中的选择不参与本次“下载所选”。
- Shift + 单击连续选择；在图片列表中 Ctrl+A 全选，空格切换当前复选框。输入目录名时 Ctrl+A 保持普通文本全选行为。
- 相同图片字节只保留一次；不同位置重复出现的图片，只要其中一次出现可见，就属于可见范围。

“一键下载全部”保存当前范围和尺寸筛选下的所有可保存图片，无需先勾选。“下载所选”只保存当前范围内所选图片。

默认快捷键 `Alt+Shift+D` 读取当前页面并保存当前偏好范围内全部图片。仅在已记住目录的写入授权有效时直接写入；首次或失效时停在侧栏，等待点击下载进行授权。重新打开侧栏不会重复执行同一次快捷下载。快捷键可在 Chrome 扩展程序的快捷键设置中修改。

“刷新图片”重新读取来源页面，会清空当前选择与当前内存中的失败重试队列。图片资源无法取得时仍显示在清单里，显示原因，可刷新后重试，不以预览失败隐藏图片。

## 目录、命名与重试

首次可以直接点击下载按钮选择目录，也可先用“选择目录”按钮设置。目录句柄保存在扩展本地 IndexedDB；浏览器可能撤销写入授权，重新授权必须由用户点击。

默认在根目录内用页面标题创建子目录，可以编辑或取消。名称中的 Windows 禁止字符会清理，保留设备名会避让，空名称使用“未命名页面”；界面显示实际清理后的保存位置。

按来源页面序号保存为 `001.jpg` 等，选择子集保留原编号。文件扩展名按图片 MIME 确定，图片内容不转码。PNG/APNG 保留全部原字节，动态图不转成单帧。

已有文件通过 ` (1)`、` (2)` 后缀避让，不主动覆盖或删除。多个本扩展面板的保存操作用同一写入锁串行执行；外部程序恰好同时创建同名文件的情况，浏览器目录 API 没有独占创建保证，不做绝对并发保证。

单个失败不影响其他图片。“重试未成功项”只处理上次批次未成功的图片，使用界面此时显示的目录配置。点击后将图片、根目录和子目录冻结为新批次；写入期间禁用修改。

“停止后续保存”会先完成当前文件，再停止剩余图片。已成功的文件保留，尚未处理的项可重试。每次成功写入后读取文件并核对 SHA-256。

面板或浏览器关闭可能中断保存。本地记录逐项保存状态，不保存整批图片字节；重新打开会提示可能中断的任务及已记录的成功数量。不会跨重启自动恢复写入。可查看报告、重新读取来源并手动选择未完成图片。失败时可能留下尚未写完或为空的文件；扩展不会自动删除它们。

## 报告与兼容边界

“导出报告”生成包含构建标识、来源、提取数量、尺寸、哈希、保存结果和错误的 JSON，由 Chrome 常规下载保存，不包含图片字节。分享前可以检查来源 URL 和标题；扩展不会自动上传报告。

已实现的扫描范围：普通 img、开放 Shadow DOM、同源框架，以及资源时间记录中可确认已加载的 CSS 背景图。跨域框架会提示未扫描；关闭的 Shadow DOM、canvas 内绘制、虚拟列表已经卸载的图片和未记录的背景资源不保证取得。

可见范围采用几何与 CSS 判断，不检测其他元素的覆盖、复杂遮罩或旋转后的逐像素可见性。没有“所有网站均支持”的保证。

扫描上限为 30000 个元素 / 5000 张图片；页面快照上限为 150 MiB。达到扫描上限提示可能不完整，快照超限拒绝继续提取。支持 JPEG、PNG/APNG、GIF、WebP、AVIF、SVG、BMP、ICO；其他格式、缺失资源、地址映射冲突或内容不像图片时，保留明确失败状态。

扩展代码没有远程请求、远程脚本和 Cookie 读取功能。Chrome 生成快照时可能获取网页自己的额外依赖；不据此宣称整个快照过程绝对没有网络访问。

## 常见问题

**为什么图片数量比正文多？** 扫描会包含页面上的其他已加载图片。先设置最短边筛选，排除小图与图标，再用“下载所选”或“一键下载全部”。尺寸筛选不是正文识别；需要保留小图时改回“不限尺寸”。

**为什么编号不是从 001 连续开始？** 子集保留来源清单编号。例如勾选第 5–7 张，会保存为 005、006、007；同名文件另加避让后缀。

**目录授权失效怎么办？** 在侧栏点击授权或下载按钮重新授权；也可以更换目录。自动快捷下载不会代替用户完成目录授权。

**为什么页面滚动后范围没有自动变化？** 已捕获的图片任务保持固定。使用“滚动后更新可见范围”更新可见性；要加入后来加载的新图片，使用“刷新图片”，它会清空当前选择和重试队列。

**如何反馈失败？** 导出报告，记录浏览器版本、操作步骤和界面错误。公开提交前移除报告中不想公开的 URL、标题、目录名与错误路径；一般不需要分享真实图片字节。
